# Korean Canvas Tutor

A minimalistic white/grey themed web app rendered entirely on a HTML5 canvas for learning basic Korean.

## Features
- Hangul alphabet flashcards (including double consonants and batchims).
- Essential tourist words.
- Scenario-based phrases for introductions, restaurants, cafés, and hotels with possible replies and easy acknowledgements.
- Multiple-choice quizzes.
- Pronunciation via Web Speech API.
- LocalStorage daily progress tracking.
- PWA manifest for adding to iOS home screen.

## Usage
Open `index.html` in a modern browser (iOS Safari 18.6 supported). Use the menu to study flashcards, practice phrases, or take quizzes. Progress is saved per day.

To install as an app on iPhone:
1. Open `index.html` in Safari.
2. Tap the Share icon and select **Add to Home Screen**.
